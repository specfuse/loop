The six ways work moves through a Specfuse project: where each one starts, what the driver does on its own, and the exact points where it stops for you. Pick a lifecycle, then click any stage.

One rule explains every checkpoint. The loop automates execution, not judgment. Every place it stops is a place where going on would mean guessing at something only you can decide. It halts rather than guesses, and it says why.

A visual companion to lifecycles.md and concepts/monitoring-to-fix.md, which stay the source of truth. In a Specfuse project this page lives at .specfuse/docs/flows.html and is refreshed by specfuse upgrade, so it always describes the specfuse-loop version that installed it.
